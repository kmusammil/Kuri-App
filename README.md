# Kuri-App

A modern web application for managing community Kuris/Chitties.

## Development

Requirements:
- Node.js 20+
- A Supabase project

Install dependencies:

```bash
npm install
```

Copy `.env.example` to `.env.local` and add the Supabase project URL and publishable key.

Run the app:

```bash
npm run dev
```

Open http://localhost:3000.
